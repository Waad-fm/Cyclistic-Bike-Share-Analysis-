Cyclistic Bike-Share Data Analysis
📌 Executive Summary
This project analyzes 12 months of Cyclistic bike-share data to identify key differences between casual riders and annual members, helping design a targeted marketing strategy to convert casual riders into annual members.
🛠️ Tools & Technologies Used
SQL (BigQuery): Data extraction, aggregation, and preparation.
Tableau Public: Interactive dashboard (https://public.tableau.com/views/CyclisticAnnualTripAnalysis/CyclisticAnnualTripAnalysisUserBehaviorDashboard?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

🔎 Key Insights
Seasonality: Peak usage occurs during summer months (June–August) for both user types.
Weekly Patterns: Member trips peak during weekdays (commuting hours), while casual trips spike on weekends.
Rideable Preference: Casual users utilize docked bikes significantly more than annual members.
